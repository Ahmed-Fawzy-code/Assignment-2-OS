#ASSIGNMENT 2

This is the README for assignment 2 , with almost everything you might need.

## Prerequisites

Make sure you have both gcc (C compiler for the C files) and mark to run the 
markup files.
To install gcc , use : sudo apt install gcc
To install mark , use : sudo apt install mark 

##How to view the Assignment contents

To run diffrent parts of the assigment :
	fork section : run this command "mark fork"
	Creating a process section : There is a screenshot with the section commands in use
	Killing a proccess section : Another Screenshot exists with the Section commands in use 
	Stopping and resuming section : Yet Another screenshot exists with the section commands in use :( 
	Linker Section : run this command "mark linker"
	Loader Section : run this command "mark loader"
That should be all the assignment contents .
Dont forget to check out the screenshots that contain stuff like the commands , expected results , etc..
